# Texture pack folder

Drop Minecraft-style block and item textures here to replace the built-in
painted ones. The game reads them at startup.

Use Minecraft's file names and folders:

    assets/pack/block/grass_block_top.png
    assets/pack/block/oak_log.png
    assets/pack/item/stick.png

An unzipped resource pack works too (`assets/pack/assets/minecraft/textures/...`).
Anything missing keeps the painted texture. Grass, leaves and water should be
gray, like Minecraft's: the game colors them by biome.

Everything in this folder except this README is ignored by git, so textures
you don't have the rights to share stay on your machine.
